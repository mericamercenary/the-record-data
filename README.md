# THE RECORD data

This repository holds only the public congressional record data for THE RECORD app.

There is no app code here, and there are no secrets. Anyone can read these files.

The app downloads them as plain public files. The download sends nothing about the person using the app: no account, no saved place, no location, and no tracking.

The files the app reads are in `feed/`:

- `feed/manifest.json` lists the weeks
- `feed/weeks/<week>.json` is one week of Matters and Actions
